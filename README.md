# Projeto Dogs - Origamid 🐶

Projeto desenvolvido durante os estudos do curso de React da Origamid, com foco na criação de uma aplicação completa utilizando React e consumo de API.

O objetivo do projeto foi praticar conceitos importantes do desenvolvimento front-end moderno, construindo uma rede social para cachorros com funcionalidades reais como login, cadastro, feed, upload de imagens e interação com API.

## 📌 Sobre o projeto

O Dogs é uma aplicação desenvolvida em React que simula uma rede social voltada para compartilhamento de fotos de cachorros.

Durante o desenvolvimento do projeto foram trabalhados diversos conceitos importantes do React, incluindo:

- Componentização
- React Router
- Hooks
- Context API
- Consumo de API
- Gerenciamento de estado
- Formulários
- Autenticação de usuário
- Responsividade
- Organização de projeto

---

## 🚀 Tecnologias utilizadas

As principais tecnologias utilizadas foram:
